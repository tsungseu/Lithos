# 知序 3.0 工作区

界面参考 Obsidian 的窄工具栏、文件侧栏、标签页、阅读区和状态栏组织方式，由本项目独立实现。使用 Obsidian 默认风格的灰黑／白灰底色和紫色强调；阅读宽度和排版参考 [Minimal](https://github.com/kepano/obsidian-minimal)，命令和设置组织参考 [Sample Plugin](https://github.com/obsidianmd/obsidian-sample-plugin)。本应用不加载 Obsidian 插件，也不依赖 Obsidian 安装。

- 左侧工具栏切换首页、项目空间、知识库、使用指南和设置。
- 顶部标签可切换及关闭；关闭标签不会删除资料或草稿。
- 顶部侧栏按钮收起或展开导航。
- Ctrl + O 打开快速切换，输入项目或页面名称，Enter 打开首项；Esc 关闭。
- Ctrl + P 打开命令面板，支持新建项目、打开图谱、切换侧栏、模型设置和手动沉淀。仅在已选项目时提供手动沉淀。
- Ctrl + , 打开设置；可设置深色、浅色、跟随系统和字号。首次使用默认深色，升级保留已有偏好。
- 项目空间保留资料预览、Office 阅读、模型 ID 和 Effort 选择、人工草稿及审核入库。
- “这次希望沉淀什么”提供综合经验、问题复盘、测试验证、架构设计、数据闭环、交付总结六类预设。离线推荐按项目与所选文件名匹配；输入框内按 Tab 采用可见建议，Esc 忽略，Shift + Tab 正常切换焦点。可直接编辑自定义目标。
- 点击“模型建议”使用当前供应商、模型和 Effort，只发送项目名称、所选文件名及当前目标，不发送资料正文。返回提示词先显示，采用后才修改目标；切换项目或编辑目标会丢弃过期响应。生成失败时仍可使用预设和自定义。
- 知识库左侧浏览和搜索真实目录，中间阅读文档或查看图谱；双击目录节点直接展开。
- 图谱和预览之间的分隔条可拖动调宽；聚焦后左右方向键调整，Home/End设为最窄/最宽。宽度保存在本机；“展开预览”独占阅读，“返回图谱”恢复。窄窗口自动上下排列。
- Markdown表格、列表、代码块和外部链接使用统一安全渲染。宽表可横向滚动；HTML脚本和事件被清理，图片不自动联网加载。
- 模型供应商和 API Key 继续保存在当前设备的浏览器数据中，升级无需重新填写。只在主动调用时向所选接口发送请求。

网页版本：双击“启动工作台.cmd”，打开本机服务地址。安装版本：运行 Setup 安装程序，再打开“项目知识工作台”。界面资源均随包提供，离线阅读无需联网。
