# 知识管理与安全编辑

知识库读取工作区的 `03_技术知识库`，项目原始资料继续在项目空间中阅读和提炼。界面参考 Trilium 的目录树、文档标签和辅助栏，保留曜石品牌与 Obsidian 配色。

## 查阅与组织

单击文件打开预览标签，双击固定标签；修改中的标签自动固定。收藏、最近 50 项访问、保存搜索、展开目录和阅读位置按工作区保存在应用数据目录。目录行悬停后的聚焦按钮仅改变导航范围，不移动目录。导航分隔条支持拖动与左右方向键。

搜索支持全库或当前目录、名称或正文和文件格式筛选。首次进入工作台后后台建立本地 SQLite 索引；完成前搜索结果可能不完整。文件在其他程序中修改后，使用“重新读取”或设置中的“重新扫描”。MD、TXT、DOCX、文字 PDF 可提取正文；扫描 PDF 不进行 OCR。超过 12 MiB 仅索引文件名，正文最多前 20 万字符。设置的“搜索与历史”列出限制、失败文件及进度。

Markdown 目录可跳转到章节；普通相对链接与 `[[笔记名]]` 打开本地笔记。优先匹配相对路径，同名笔记显示候选列表，失效链接显示提示。引用与被引用根据已索引文件解析，刷新索引后反映外部变化。来源项目只读取原有来源记录。

## 编辑与恢复

点击“编辑”修改完整 UTF-8 Markdown，Ctrl+S 或保存按钮写入原文件。超过 1 MiB、非 UTF-8、开源项目分支和检测到 Git 仓库的资料为只读。新建笔记选择已经存在的目录；同名文件不覆盖。

输入停止 2 秒后保护本机恢复草稿，原文件不变。异常退出后重新打开文档可选择恢复；关闭修改中的标签可以保存、放弃或取消。浏览器强制关闭前最后不足 2 秒的输入可能尚未落盘，请以“恢复草稿已保护”提示为准。

每次内容实际变化并保存前保留磁盘原版本；保存使用 SHA-256 校验和临时文件替换。发现其他程序修改时，不覆盖：可比较内容、加载磁盘版本或另存当前编辑。历史面板显示差异；恢复为新版本时保留恢复前内容。历史不自动清理。

## 数据位置与备份

知识管理状态位于应用数据目录的 `knowledge/<工作区标识>/knowledge.sqlite3`，包含可重建的检索缓存，以及不可从原件重建的历史、恢复草稿和用户偏好。不要把整个数据库当成可随意删除的缓存。备份时关闭应用，将工作区原文件和应用数据目录一起备份。API Key 继续沿用已有本机配置，不保存在知识索引中。

项目模型提炼继续要求核对来源和审核后入库。直接新建的个人知识笔记不自动标记为“已审核”或“已验证”。
