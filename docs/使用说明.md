# 欢迎使用 Lithos

Lithos 是以本地文件为基础的知识工作台。你可以阅读和编辑笔记、连接相关知识，也可以把项目资料提炼为经过审核的知识文档。

## 开始使用

安装版打开 Lithos 即可使用。便携版完整解压后运行包内启动程序；网页需要本机服务保持运行。打开设置 → 文件与链接，确认资料根目录。可以选择任意已有目录，无需预建固定名称的文件夹。知识库名称和存放位置可以自定义；位置填写 `.` 表示所选工作区，也可填写相对路径或完整路径。保存时自动创建不存在的知识库目录，保存后自动生效并刷新文件列表，后续沉淀使用新知识库；已有资料不会自动搬迁。端口变更在下次启动生效。

从左侧文件列表打开已有资料，或在可写知识目录创建第一篇 Markdown 笔记。普通知识笔记可以独立编写，无需先调用模型。

## 认识工作区

- 最左侧功能栏提供快速切换、图谱、日记、模板、命令面板，以及项目空间与知识沉淀入口。底部齿轮打开设置，帮助打开本指南。
- 导航面板可以切换文件、搜索和书签。展开目录查阅文件，也可以定位当前笔记或聚焦某个目录。
- 顶部标签保存正在查阅的内容。单击文件用于预览，双击固定标签；“＋”打开空白标签页。
- 文档辅助栏展示文内目录、引用、来源和历史。更多菜单提供文档与标签操作。

拖动分隔线调整面板宽度；窗口较小时可收起导航与辅助栏。设置 → 界面中可以恢复项目双栏默认比例。

## 编写笔记

打开可编辑 Markdown 后切换至编辑模式。使用标题、列表、表格和代码块组织内容，通过工具栏插入常用格式。阅读模式渲染 Markdown，宽表格和代码可以横向滚动。

按 Ctrl+S 才会保存原文件。停止输入后应用保留本机恢复草稿；异常退出后可按提示恢复。关闭未保存标签时选择保存、放弃或取消。磁盘文件被其他程序修改时，先处理冲突，再决定加载磁盘内容或另存笔记。

项目原件、开源资源及 Git 仓库默认只读。超过编辑大小限制或不支持编码的文件保持只读。Office 等格式通过对应阅读器预览，版式不适合阅读时可下载原件查看。

## 连接与查找知识

使用相对 Markdown 链接或 `[[笔记名]]` 连接笔记。同名文件需要选择正确候选；失效链接需要修正目标。引用关系来自文件内容，不由模型推测。

搜索可选择全库或当前目录、名称或正文，并按文件类型筛选。常用条件可以保存为搜索，重要资料可加入书签。正文检索受提取能力与索引状态限制，扫描图片型 PDF 不等同于可搜索文本。

图谱用于浏览目录和实际关联。双击目录直接展开，单击文档预览，必要时打开为标签。文内目录可以直接跳转到对应章节。

## 日记与模板

点击“今天的日记”打开当天笔记，首次使用才创建；再次打开不会覆盖内容。日记默认以本地日期命名。

在活动可写笔记中选择“插入模板”，在光标处插入选定内容。支持 `{{date}}`、`{{time}}`、`{{title}}`，插入后可以撤销，保存前不覆盖文件。设置 → 日记与模板中管理相关目录。内置复盘、问题分析和技术调研模板按需选择。

## 从项目资料沉淀知识

项目空间提供左右两栏：左侧预览原件，右侧完成 AI 知识沉淀。拖动中间分隔线自由调宽，双击恢复默认；也可以临时展开其中一栏。

1. 打开项目，勾选资料，或在原件预览中点击“加入沉淀材料”。
2. 在右侧说明希望沉淀什么，可使用提示建议或自行编写；选择本次模型 ID 和 effort 等级。
3. 预览准备发送的资料，确认后调用模型。仅配置模型或打开页面不会发送项目资料。
4. 编辑草稿，核对来源、验证依据及适用边界。
5. 审核后入库。正式知识文档保存在知识库，原始证据仍留在项目中。

不使用 AI 时可以新建手动草稿。已有草稿可通过材料与草稿区域重新打开。项目建议按计划与需求、方案与设计、开发与验证、问题与改进、交付与验收组织，子目录按需创建。
